# Research Projects

This repository contains a  collection of academic-style data analysis projects completed using Python, R, and statistical modeling techniques. Each project explores a real dataset, applies appropriate analytical methods, and communicates findings through clear visualizations, written reports, and presentation materials.  

These projects were developed through university and independent research, and they demonstrate my ability to work with real-world data, evaluate statistical models, and present results in a professional, reproducible format.

Each project folder includes its own in-depth README with methodology, results, and documentation. This top-level overview summarizes the purpose and focus of the collection.

---

## Repository Structure

### **1. Life Expectancy & Fertility**
A modeling-focused project examining the relationship between global fertility rates and life expectancy.  
Skills demonstrated include:
- Exploratory data analysis  
- Regression modeling
- Model comparison using error metrics  
- Visualization and interpretation  
- Academic-style reporting and poster creation  

This is my flagship research project and includes both undergraduate work and a polished Jupyter Notebook analysis.

---

### **2. Predicting GPA at WIU**
A statistical investigation into factors associated with student GPA, using survey data collected at Western Illinois University.  
Key components include:
- Data cleaning and preparation  
- Exploratory analysis of demographic and behavioral variables  
- Regression modeling and evaluation  
- Presentation of findings in a clear, accessible format  

The project includes the original survey dataset, a full notebook analysis, and a presentation summarizing results.
